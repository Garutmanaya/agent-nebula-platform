# Changelog

## 1.1.1

Initial public release of Agent Nebula Platform.

- Integration with the official A2A Python SDK for agent server and client workflows.
- Configurable security composition and Agent Nebula onboarding integrations.
- Plugin lifecycle, runtime configuration, health checks, and observability support.
- A2UI integration for declarative agent interfaces.

See the [README](README.md) and [documentation index](docs/README.md) for supported functionality and current limitations.
