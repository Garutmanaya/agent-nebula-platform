# Terminology

**Agent Nebula** — enterprise control plane, registry, OAuth Authorization Server, discovery, lifecycle, trust, and RBAC authority.

**agent-nebula-sdk** — protocol and cryptographic implementation library.

**Agent Runtime** — pluggable application integration and agent runtime layer.

**Agent Studio** — planned reference-agent, A2UI showcase, and test-fleet repository.

**Embedded mode** — runtime integrates into an existing host that retains infrastructure ownership.

**Standalone mode** — selected runtime preset owns configuration loading, managed HTTP/TLS resources, FastAPI/Uvicorn, cache, and lifecycle.

**Skill** — stable business-operation declaration with exact required scopes.

**Protected resource** — Provider Agent/resource that validates access tokens and DPoP.


**A2UI surface** — declarative UI message stream rendered by a trusted client catalog.

**Authoritative document** — complete source Agent Card or Protected Resource Metadata, including unknown extensions.
